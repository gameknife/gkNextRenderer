# Subprojects & Applications List

gkNextEngine hosts 15+ standalone subprojects across rendering experiments, tools, simulation prototypes, and benchmarks.

---

## 🎨 Render & Editor

- **`gkNextRenderer`**: Main renderer with real-time path tracing, hybrid pipelines, and SHARC caching.
- **`gkNextEditor`**: ImGui editor for node materials, live cvar tuning, and PIE mode.
- **`ScadStudio`**: OpenSCAD modeling, CSG evaluation, and ScadRig animation playground.
- **`RmlUiDemo`**: RmlUi HTML/CSS UI engine integration.

---

## 🕹️ Game & Simulation

- **`AirportSim`**: Airport ecology, SCAD POIs, passenger queues, NavGrid A*, and local LLM agent behavior.
- **`StudioSim`**: Studio simulation with local LLM events and career palettes.
- **`MagicaLego`**: Voxel and LEGO scene building with Jolt physics.
- **`BrickPlayer`**: Official LDraw digital brick interactivity.
- **`Brotato3D`**: Top-down survival horde shooter.
- **`NextDayz`**: Open-world exploration, AI behavior trees, and third-person combat.
- **`NextTotalWar` / `NextRA`**: Massive legion battle tactics and Lockstep deterministic sync.

---

## ⚡ Benchmark & Tools

- **`gkNextStillBenchmark`**: Static scene framerate and visual benchmark.
- **`gkNextMotionBenchmark`**: Dynamic camera benchmark with CSV profiling export.
- **`gkNextVisualTest`**: Automated visual regression testing suite.
- **`Packager`**: Asset packaging CLI.
