# SCAD 资产目录约定

`assets/scad` 同时承载可复用 Kit、人工维护场景、产品专属场景与生成产物。为避免破坏现有
游戏和测试引用，不对历史文件做批量迁移；新增内容按以下约定收纳：

- `lib/kit_*.scad`：只放可复用模块库，不放完整场景。
- `scenes/*.scad`：ScadLibrary 人工组装、可长期编辑的通用场景。
- `<product>/*.scad`：由具体产品拥有的场景，例如 `coldwar/`、`brotato3d/`。
- `characters/*.scad`：角色 Rig 与角色资产，不出现在场景组装浏览器中。
- `specs/*.json`：声明式场景规格。
- `gen/*.scad`：由 `gnb scad compose` 等工具生成的产物；可以在 ScadLibrary 中打开和
  临时编辑，但重新生成时会覆盖手工改动。
- 根目录现有 `.scad`：兼容保留。新建通用场景优先放入 `scenes/`。

## ScadLibrary 场景组装

所有通过 `use` 或 `include` 引用 `kit_*.scad` 的场景都会出现在“场景组装”模式：

1. 复杂手写场景使用“源码”页完整编辑；“预览”会先生成工作区副本，不覆盖源文件。
2. 带 `generated by ScadLibrary scene assembly` 文件头的平铺场景，还可以在“对象”页调整
   模块、XY 位置、Z 轴旋转、统一缩放与调用参数。
3. “导出场景”默认写到 `assets/scad/scenes/`，并始终使用相对 Kit 路径。
4. 保存范围被限制在 `assets/scad` 内，并禁止覆盖 `lib/` 中的 Kit。

对象化格式刻意保持简单：一个顶层模块调用占一行，变换顺序固定为
`translate(...) rotate(...) scale(...) module(...);`。循环、条件、局部 module 和布局组合器
仍应在“源码”页编辑，避免工具错误改写其语义。
