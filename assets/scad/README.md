# SCAD 资产目录约定

`assets/scad` 同时承载可复用 Kit、人工维护场景、产品专属场景与生成产物。为避免破坏现有
游戏和测试引用，不对历史文件做批量迁移；新增内容按以下约定收纳：

- `lib/kit_*.scad`：只放可复用模块库，不放完整场景。
- `scenes/*.scad`：ScadLibrary 人工组装、可长期编辑的通用场景。
- `<product>/*.scad`：由具体产品拥有的场景，例如 `coldwar/`、`brotato3d/`。
- `characters/*.scad`：角色 Rig 与角色资产，不出现在场景组装浏览器中。
- `specs/*.json`：声明式场景规格。
- `gen/*.scad`：由 `gnb scad compose` 等工具生成的产物；可以在 ScadLibrary 中打开和
  临时编辑，但重新生成时会覆盖手工改动。
- 根目录现有 `.scad`：兼容保留。新建通用场景优先放入 `scenes/`。

## ScadLibrary 场景组装

所有通过 `use` 或 `include` 引用 `kit_*.scad` 的场景都会出现在“场景组装”模式：

1. 复杂手写场景会按真实 SCAD 语义求值变量、条件、循环、局部 module 和 `use/include`
   关系，并尽可能把最终 Kit module 实例展开到“对象”页；位置、三轴旋转、三轴缩放、颜色
   和求值后的参数均可编辑。展开结果必须“另存为”副本，避免覆盖原文件的程序结构。
2. 带 `generated by ScadLibrary scene assembly` 文件头的平铺场景可无损往返“对象”与
   “源码”页，并允许直接保存。
3. 在“对象”页点选实例后，视口会在该对象原点显示移动/旋转 Gizmo。拖动期间实时更新
   运行时 Scene Node 和 SCAD Z-up 坐标；松开时只写回 `translate` / `rotate`，不重新解析
   或上传整场景。平铺场景直接写回；从复杂逻辑求值出的对象写到
   `scenes/<原名>_editable.scad`，不覆盖原始生成逻辑。
   也可以直接点击视口中的几何；Picking 命中渲染子节点后会沿父链找到所属 Kit 实例，
   同步右侧对象列表的高亮和滚动位置，再进入同一套 Gizmo 编辑流程。
4. “导出场景”默认写到 `assets/scad/scenes/`，并始终使用相对 Kit 路径。
5. 保存范围被限制在 `assets/scad` 内，并禁止覆盖 `lib/` 中的 Kit。

可编辑副本格式刻意保持简单：一个求值后的 Kit module 实例占一行，变换顺序固定为
`translate(...) rotate(...) scale(...) module(...);`。循环、条件、局部 module 和布局组合器
会在副本中展开为确定实例；需要继续维护其生成逻辑时，应编辑原文件的“源码”页。

含 `gk_terrain(TERR)` 的场景会额外保留 TERR 声明和地形调用源码。地形不作为普通 Kit
实例进入对象列表，但在对象预览、另存可编辑副本以及后续 Gizmo 写回时始终保留。
