# Specification: MagicaLego UI Modernization & Gamification

## 1. Overview
本任务旨在对 MagicaLego 的编辑器界面进行深度视觉重构，将其从传统的“软件感”界面升级为更加现代、沉浸且具有“游戏感”的 UI。核心方案是将传统的停靠式面板（Docking）替换为悬浮式的 HUD 风格，并引入玻璃拟态（Glassmorphism）、乐高主题配色以及 `ImAnim` 动效库。**开发原则上尽量将修改局限在 MagicaLego 的源代码目录，但允许为了完善底层 UI 设施对 Engine 库进行必要的扩展或调整。**

## 2. Functional Requirements
- **悬浮 HUD 布局**：将编辑器面板（如 Inspector, Scene Graph, Toolbar）从固定停靠状态改为悬浮半透明覆盖层，直接置于 3D 视图上方。
- **自定义视觉样式**：
    - **玻璃拟态**：实现圆角、半透明背景。
    - **主题配色**：采用乐高品牌色彩（如 Lego Yellow 作为强调色，Tire Gray 作为背景基调）。
    - **图标与字体**：集成现代化的自定义图标库（如 FontAwesome）和高性能现代无衬线字体。
- **动效集成 (ImAnim)**：
    - **面板动效**：实现面板的平滑滑入/滑出或缩放淡入效果。
    - **控件反馈**：为按钮、滑块等添加悬停缩放和点击回弹的动态反馈。
    - **状态切换**：在不同编辑模式（选择/移动/旋转）切换时，HUD 元素进行平滑过渡。
    - **通知系统**：实现动画化的弹出式通知。

## 3. Non-Functional Requirements
- **代码局部性**：核心逻辑应位于 `MagicaLego` 目录下，`Engine` 的修改应仅限于通用的 UI 样式支持或 `ImAnim` 的集成基础。
- **性能保持**：UI 动效和半透明计算不应显著降低引擎的帧率（FPS）。
- **可配置性**：支持通过配置文件或设置调整透明度和动效强度。
- **一致性**：确保所有 UI 元素在不同分辨率和平台（PC/移动端）下保持比例一致。

## 4. Acceptance Criteria
- [ ] 所有编辑器面板均已转为悬浮 HUD 风格。
- [ ] 界面主题色符合乐高风格，字体和图标完成更新。
- [ ] `ImAnim` 成功集成，关键交互（面板开关、按钮点击）均有流畅动效。
- [ ] 3D 场景在 HUD 面板下方清晰可见。
- [ ] 无明显的 UI 渲染性能抖动。

## 5. Out of Scope
- 本阶段不涉及底层 3D 渲染功能的修改。
- 不涉及启动画面（Start Screen）或主菜单的重构。
- 不涉及节点材质编辑器的视觉修改（仅限 MagicaLego 核心编辑器）。
