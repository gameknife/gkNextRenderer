# 产品设计与风格指南

## 品牌色调与沟通
- **亲切且富有启发性**：我们的目标是降低高性能图形技术的准入门槛。在文档、教程和社区互动中，应保持亲切的语气，鼓励开发者尝试新技术，并清晰地解释复杂的原理，激发其创造力。

## 视觉设计原则
- **现代简约**：
    - **UI/UX**：追求清晰的界面层级和直观的交互流程。
    - **编辑器设计**：向现代专业创作工具（如 Blender）看齐，注重工作区的高效利用和视觉上的整洁，减少不必要的视觉噪音，让开发者专注于创作本身。

## 语言与文档规范
- **中英双语并行**：
    - **代码层**：代码注释、变量命名及 API 定义应首选英语，以符合国际开发惯例。
    - **指南层**：提供高质量的中文教程 and 开发文档，确保国内开发者能够深入理解引擎核心机制，同时保留英文原版文档，方便全球开发者查阅。

## 社区与协作准则
- **响应迅速且开放**：我们将积极维护 Issue 列表，对开发者的反馈给予及时响应。
- **质量优先 (Quality First)**：坚持严谨的 Code Review 流程。任何代码的合并都必须符合项目的代码风格指南和性能要求，确保引擎基座的稳固。
- **透明的设计决策**：定期更新项目路线图 (Roadmap)，公开重大功能的设计思路，让社区清晰了解 gkNextEngine 的成长轨迹。
