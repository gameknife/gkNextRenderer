# Initial Concept
本项目旨在利用现代 C++ 和 Vulkan 技术，构建一个高性能、生产级别的通用 3D 游戏引擎。它不仅关注前沿渲染技术的实现，更强调作为商业游戏开发工具的实用性、跨平台能力和高性能架构。

# 核心愿景
gkNextEngine 的目标是成为一个具备商业竞争力的 3D 游戏引擎。它致力于为开发者提供一套完整的工具链和运行时环境，支持从高品质 PC 渲染到高效移动端呈现的全场景开发。

# 目标用户
- **独立游戏开发者与小型工作室**：为其提供构建高性能跨平台 3D 游戏的基础设施，降低底层技术准入门槛。

# 核心功能与特性
- **极致真实感渲染**：深度集成硬件光线追踪、实时全局光照 (GI) 及路径追踪技术，提供电影级的视觉表现。
- **卓越的跨平台支持**：支持 Windows、Linux、macOS、Android 及 iOS，确保游戏在不同设备上具有一致的体验和性能。
- **高性能运行时架构**：采用全 GPU-Driven 管线、Bindless 渲染以及高效的多线程任务调度系统，充分释放现代硬件潜力。
- **全方位模块集成**：内置 Jolt Physics 物理引擎、基于 ImGui 的编辑器 UI 系统以及完善的音频与输入支持，提供开箱即用的开发体验。

# 技术约束与非功能需求
- **高性能与低功耗**：针对移动端进行深度优化，确保在性能受限的设备上仍能保持流畅运行与较低的资源占用。
- **稳定性与可维护性**：坚持高质量代码标准，利用 Catch2 框架进行严格测试，构建稳健的引擎基座。
- **高效开发体验**：提供标准的跨平台命令行工具和现代化的 CMake 构建体系，支持一键式依赖管理与构建，显著提升开发与迭代效率。
- **现代资产工作流**：支持 .pkg 资产打包系统及 AVIF 等现代图像格式，优化游戏的加载速度与分发效率。
