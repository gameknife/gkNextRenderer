## 做了什么

按 spec 7 步实施完，把 `ERT_LegacyDeferredNoAmbient` 拆成一条独立的轻量 deferred 管线，标准化光照模型并补上 CSM 阴影：

1. **UBO 扩字段**：`SunViewProjection`(单矩阵) → `SunCascadeViewProjection[4]` + `CascadeSplits`。`EnvironmentSetting::ComputeSunCascades` 实现按主相机视椎切 4 段（log-uniform 混合，λ=0.75），每段用 bounding sphere 算 ortho 矩阵。`Engine::GetUniformBufferObject` 用 `ViewProjectionUnJit` 喂数据。PathTracer 的 `FShadowMapDirectIlluminator` 临时读 cascade[0] 保持工作。
2. **Scene sunShadowMap_ D32 array**：4 个 D32_SFLOAT 单层 image (2048²，usage=DEPTH_STENCIL_ATTACHMENT|SAMPLED)，初始 layout=DEPTH_STENCIL_READ_ONLY_OPTIMAL，配 nearest-clamp 共享 Sampler。`cpuShadowMap_` 资源保留但 `MarkEnvDirty` 里的 `GenShadowMap` 调用早已注释掉，零改动即可。顺手补 `Image::TransitionImageLayout` 缺的 UNDEFINED→DEPTH_STENCIL_READ_ONLY_OPTIMAL 分支（首启会崩在这）。
3. **Bindless 第三个 binding**：`BindlessTexture.slang` 加 `[[vk::binding(2,0)]] ShadowMapArray[]` + `Bindless.GetShadowMap()` helper。`GlobalTexturePool::DescriptorSetManager` 加 binding 2 (COMBINED_IMAGE_SAMPLER, count=16)，新方法 `BindShadowMap(slot, view, sampler)`。
4. **ShadowMapPass**：`Engine/Rendering/Shadow/ShadowMapPass.{hpp,cpp}` + `Rast.ShadowMap.{vert,frag}.slang`。镜像 VisibilityPipeline 模式，自带 depth-only RenderPass + 4 个 framebuffer (per-cascade)，VK_CULL_MODE_NONE + slope-scaled depth bias(1.25/1.75)，cascade idx 走 `GPUScene.custom_data_0`。`VulkanBaseRenderer::CreateSwapChain` 创建 + 注册 4 个 cascade 到 bindless slot 0..3；`PreRender` 在 visibility pass 之后调用（HasSun 时）。
5. **NoAmbient 独立 renderer**：新建 `Vulkan::NoAmbientDeferred::Renderer`，独立 LogicRendererBase 实现。`SoftwareModernRenderer` 去掉 `simpleComposeOnly_` 双形态构造和分支。`VulkanBaseRenderer::RegisterLogicRenderer` 切到新类。
6. **重写 shading shader**：`Core.SwModernNoAmbient.comp.slang` 光照段重写为：天光 = `albedo * SampleIBLRough(N) * SkyIntensity`（去 0.03 magic），太阳 = `albedo * SunColor * NoL * shadow * M_1_PI`。CSM 选 cascade（基于 view-space 距离）+ 3×3 PCF（unrolled）+ slope-scaled bias。
7. **验证**：`gnb build --reconfigure` 全平台过；`gkNextVisualTest` 5 scenes 全部通过（PathTracing 渲染，证明 UBO/Bindless/Scene 改动不破坏 PathTracer）；最后一次跑日志 `All tests completed, exiting...`。

## 风险/遗留

- ⚠️ **NoAmbient 路径未跑过端到端可视化对比**：默认 `userSettings_.RendererType=0`(PathTracing)，visual test 也是 PathTracing；NoAmbient 需要用户从 ImGui 切到 `SoftModernNoAmbient` 才能看到效果。建议第一次跑的时候用一个 HasSun=true 的场景（KongLie3D / 室外场景）目测 CSM 阴影。
- ⚠️ **PathTracer 阴影质量降级**：原来 `FShadowMapDirectIlluminator` 用单一 `SunViewProjection` 配 CPU 生成的 R32 shadow map；现在改读 `SunCascadeViewProjection[0]` 但 PathTracer 自己的 `ShadowMapSampler` 还指向旧的 `cpuShadowMap_`，而 CPU 生成已经停了。PathTracer 看到的 shadow map 全是 0（默认初始化），导致阴影行为可能偏差。**后续单独一票升级 PathTracer 到 GPU CSM 采样**。
- ⚠️ **Y 翻转方向假设未实测**：我推导是 glm::ortho 输出 + Vulkan 默认 viewport.y 不翻 → UV.y 计算用 `(NDC.y+1)*0.5` 不再翻 Y，与 PathTracer 旧 CPU shadow 路径相反。第一次跑 NoAmbient 看到阴影方向不对再回来翻 Y。
- CSM split 参数 (λ=0.75)、bias (0.0008)、PCF kernel (3×3) 都是常见起点，第一次落地大概率需要按目测微调。
- 旧 `cpuShadowMap_` + `FCPUAccelerationStructure::GenShadowMap` 代码仍在但不再被调用，等 PathTracer 升级完一起删。
- `SHADOWMAP_SIZE=4096` 常量在 [UniformBuffer.hpp:25](src/Engine/Assets/GPU/UniformBuffer.hpp:25) 仅服务于旧 cpuShadowMap_；新 CSM 用 `Scene::kSunShadowResolution=2048`。一起留到清理时统一。
- ImGui `GraphicsDebugPanel`/`gkNextVisualTest` 字符串 "SoftModernNoAmbient" 仍引用同一个 enum，无需改动。
