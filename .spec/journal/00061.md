## 做了什么

- 把 NoAmbient 着色中的 sky diffuse 拆到全分辨率 `RT_AMBIENT`，`RT_SINGLE_DIFFUSE` 仅保留太阳直射、自发光与 sky miss，保证 AO 只遮蔽天光。
- 新增半分辨率 `R16F` `RT_GTAO`，实现 2 切片 × 4 步 horizon AO、逐帧采样抖动、世界半径衰减与 thickness heuristic。
- 新增全分辨率联合双边上采样，以深度、法线和空间距离约束 AO，并将 `ambient * ao` 合回 diffuse 后复用现有 `ReProjectSimple` 时序收敛。
- 在 `SoftwareModernNoAmbientRenderer` 中接入 GTAO/compose 两个 compute pass、读写 barrier 与 `gtao pass` GPU timer。
- 新增 `r.gtao.enable/radius/strength/thickness/debugMode`，调试模式支持显示 AO 和未遮蔽天光；同步更新设计文档及文档索引为已完成。

## 验证

- `.\gnb.bat build gkNextRenderer gkNextUnitTests`：通过；新增及受公共 UBO 影响的 Slang shader 均重新编译通过。
- 使用 renderer type 4 对 `assets/models/playground.glb` 生成 GTAO off/on/AO debug 三组 agent-validation 截图，均成功启动并记录 `uploaded scene [playground.glb] to gpu`。
- 肉眼检查：AO 调试图在墙根、灌木、桥架和物体接触处形成连续遮蔽；最终图只压低天光接触区域，太阳直射与自发光路径不受影响，未见明显半分辨率漏边或 halo。
- 完整 `gkNextUnitTests` 在既有 `EngineTestFixture` 用例中仍会 SIGSEGV；随机顺序下分别复现于 `Load glTF Skinning Data` 和 `Dynamic Physics Offset Uses Local Space`，与本次 GTAO 路径无直接关联，未将测试套件标记为通过。

## 风险与遗留

- 当前复用颜色 TAA history；快速运动下若出现 AO 拖影，可按设计文档的可选增强增加独立 AO history。
- bent normal 属于可选质量增强，本次标量 sky occlusion 交付未实现。
- 仓库当前没有 `gnb benchmark` 命令；已埋入独立 `gtao pass` GPU timer，性能预算需由现有 profiler/benchmark target 后续采样。
