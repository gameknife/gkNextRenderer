## 做了什么

- 删除 `EditorUiState::fontIcon`。
- 删除 Editor 自行加载的 18px `Roboto-BoldCondensed + Font Awesome Solid` 合并字体，统一使用引擎 ImGui 默认字体；默认字体已在引擎 UI 初始化时合并 regular/solid Font Awesome glyph。
- 清理工具栏、标题栏和内容浏览器导航中的 `fontIcon` 条件式 `PushFont/PopFont`。
- 保留内容浏览器缩略图使用的独立 32px `bigIcon` 字体。

## 改动文件

- `src/Application/Editor/gkNextEditor/Core/EditorUiState.hpp`
- `src/Application/Editor/gkNextEditor/EditorInterface.cpp`
- `src/Application/Editor/gkNextEditor/Overlays/TitleBarOverlay.cpp`
- `src/Application/Editor/gkNextEditor/Panels/ContentBrowserPanel.cpp`

## 验证

- `.\gnb.bat build gkNextEditor`：通过；仅有既有 Superluminal PDB 链接 warning。
- `.\gnb.bat shot --target gkNextEditor --ui --frames 60`：通过。
- 肉眼检查截图：顶部工具栏、标题、内容浏览器导航及面板内 Font Awesome 图标均正常显示，无缺字方框；32px 文件夹缩略图正常。

## 风险与遗留

- 无。
