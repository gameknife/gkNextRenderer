## 做了什么

- 新增 `FProjectMeters`、`FProjectState`、`FWorkOutput` 与 `EProjectStage`，为 StudioSim 增加每日项目产出状态。
- 新增 `ProductionSystem`：员工在可用工位附近按 15 游戏分钟节拍产出 tech/design/art/polish；PM/Boss 只提供团队系数加成，不直接产点。
- 实现 Production -> Polish -> Done 阶段推进；Polish 阶段生成初始 bug，QA 确定性发现 bug，工程师优先修 bug。
- 目标选择时按关键词填入 `category` 与 `targetMeters`，产出系统不依赖 LLM。
- 在现有 StudioSim 调试 UI 中显示项目阶段、进度、四仪表、bug 数和员工当日贡献，便于验证 R1。
