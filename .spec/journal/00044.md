> 2026-07-17 清理注记：本日志是旧 Engine 内 Remote Play Phase 0 的历史快照。现行实现位于 `src/Modules/NextRemote/`，编码仅支持 Vulkan Video H.264；当前架构与限制见 `docs/designs/webrtc-remoteplay-design.md`。

## 做了什么

- 按当时的 Remote Play 设计先落地 Phase 0 基础设施；现行架构与边界见 `docs/designs/webrtc-remoteplay-design.md`。
- 接入桌面端依赖：`libdatachannel[ws,srtp]`、`openh264`、`cpp-httplib`，并在 CMake 中用 `GK_WITH_REMOTE` 做平台/依赖开关。
- 新增 `Runtime::Remote::RemoteServer` 与 `FSignalingServer`，提供 HTTP `/`、`/config` 和 WebSocket signaling hello；服务生命周期挂到 `NextEngine::Start/Tick/End`。
- 新增 `assets/remote/index.html` 作为浏览器客户端入口，能读取配置、连接 signaling WebSocket，并展示当前 HTTP/signaling/stream 状态。
- 新增 `libjuice` 和 `libdatachannel` vcpkg overlay：修正当前 registry 下 `libjuice` GitHub tarball 哈希漂移问题，并让 `libdatachannel` 走固定 commit 的 `vcpkg_from_git`，避开不稳定的 GitHub archive 下载。
