## 做了什么

- 实现 AmbientCube hit-driven residency 的路线 A MVP：新增 per-brick `AmbientBrickResidency`，由消费查询和 bake bounce 两路在 GPU 端稀疏标记命中。
- CPU brick table 周期性读取 residency，按「几何候选 + grace 窗口 + recent hit」重分类驻留 brick，并复用旧 slot、清零被驱逐 slot。
- 接入 `r.ambientCube.hitDrivenResidency`、`r.ambientCube.evictFrames`、`r.ambientCube.graceFrames`、`r.ambientCube.hitMarkTileRatio`、`r.ambientCube.residencyDebug`。
- `ClearAmbientCubeCache` 同步清理 residency；camera UBO 携带 hit mark ratio 和 debug mode；设计文档更新为路线 A 已实现。

## 风险/遗留

- 已实现路线 A（CPU readback + 重分类）。路线 B（全 GPU free-list / indirect dispatch）保留为后续性能优化，不作为当前默认路径。
- 当前 `assets/configs/cvar_user.json` 中启用了 `r.ambientCube.hitDrivenResidency=true` 作为验证配置；需要提交前按是否希望默认打开实验功能决定保留或移除。
