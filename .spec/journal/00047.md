> 2026-07-17 清理注记：本日志记录旧 Engine 内 CPU/OpenH264 MVP。Remote Play 后来迁移到 `src/Modules/NextRemote/`，当前仅支持 Vulkan Video H.264，不存在软件编码回退；现行说明见 `docs/designs/webrtc-remoteplay-design.md`。

## 做了什么

- 补齐 Remote Play 输入链路：服务端创建 unordered/低重传 input DataChannel，解析键盘、鼠标、滚轮和手柄二进制消息。
- 新增 SDL 输入注入：键鼠/滚轮通过 `SDL_PushEvent` 进入原有 `NextEngine::HandleEvent()`；远程相对鼠标使用专用 mouse id 在主线程走 `xrel/yrel`。
- 新增 SDL3 虚拟手柄封装：浏览器 Gamepad API 状态映射到 SDL 虚拟 gamepad，覆盖 `TickGamepadInput()` 的轮询路径。
- Web 客户端补齐输入采集：键盘 scancode 表、Pointer Lock 相对鼠标、鼠标按钮/滚轮、标准 gamepad 轮询。
- `FrameSource` 从测试图样推进到真实画面：复用现有 screenshot 线性图像，从 swapchain 拷回 BGRA 后缩放/转换为 I420，喂给 OpenH264 + WebRTC video track；失败时才回退测试图样。
- Remote 启动验证覆盖 HTTP `/config`、WebSocket request/offer、DataChannel SDP。
