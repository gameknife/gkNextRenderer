# #00022 AIService Agent 化 — Phase 6：AI Panel UI 升级

## 做了什么

为 AIPanel 加上 agent 模式所需的 UI 接口：步骤事件流可视化、停止按钮、模式 + 步数配置。底层数据通路（sink / cancel flag / config）现在已经就绪，Phase 7 切 `GenerateAsync` 到 agent loop 时事件会自动开始流动 —— UI 端不再需要改动。

### FEditorAIService 扩展

新增成员（`EditorAIService.hpp/.cpp`）：
- `NextAI::FInMemoryAgentEventSink agentEventSink_` + `GetAgentEventSink()` — agent loop 事件目的地（thread-safe，UI 每帧 Drain）
- `std::atomic<bool> cancelRequested_` + `RequestCancel() / IsCancelRequested()` — agent loop 每步检查的取消标志
- `bool useAgentLoop_` + `int maxAgentSteps_` + 4 个 getter/setter，`SetMaxAgentSteps` 钳到 [1, 30]
- `LoadAgentConfig()` 构造时读 `assets/configs/ai_config.json` 的 `useAgentLoop` / `maxAgentSteps` 字段（best-effort，缺失留默认）

### AIPanel UI 新增

1. **Agent Settings** 折叠区（默认关）：
   - "Use Agent Loop" checkbox
   - "Max Steps" slider 1-30
   - 灰字提示"Agent loop becomes active once Phase 7 wires it in"避免用户期望立即生效

2. **Agent Steps** 折叠区（默认关）：
   - 每帧 `service.GetAgentEventSink().Drain()` 拉新事件追加到本地 `agentEventLog`
   - 200 事件 cap（滚动覆盖），每行：`step N · phase · toolName · summary`，phase 着色（call 黄、result 蓝、error/cancelled 红、final 绿）
   - 可选 detail 缩进灰色 wrapped 显示（args / result 摘要）
   - 高度固定 10 行 + 横向滚动
   - 新事件追加时自动 scroll-to-bottom
   - "Clear" 按钮 + 事件计数

3. **Stop 按钮**：generating 时在原 Send 按钮位置右侧出现红色 Stop 按钮，点击 `RequestCancel()`。`IsCancelRequested()` 为 true 时附近显示橙色 "cancelling..." 提示

### 配置文件

`assets/configs/ai_config.json` 顶层加：
```json
"useAgentLoop": true,
"maxAgentSteps": 12,
```

## 风险与遗留

- **未手动 UI smoke test**：本 turn 无法启动 gkNextEditor 验证面板布局正确性。代码逻辑直观（折叠区 → 子窗口 → 文本），Phase 7 切换主路径后会自然激活，到时用户看到的就是真实状态
- **Agent Settings 切换不会即时生效**：当前 `GenerateAsync` 还走 legacy 单轮路径，无视 `useAgentLoop_`。Phase 7 接管后此 flag 才有意义
- **事件 ring buffer 用 `vector::erase(begin())`**：O(n) 移除头部，每超 200 条触发一次拷贝。可接受 —— 200 cap 下单次移动 ~200*sizeof(struct) = ~20KB，每秒最多几次，肉眼无感。如果 Phase 7 实测面板卡顿再换 deque
- **没有 "导出对话" 功能**：transcript 仍留在 `lastResponse_` / `agentEventLog`，没提供保存。可接受 —— gnb dashboard chat 也是这模式
- **取消语义**：当前 `RequestCancel` 设 flag 但 `GenerateAsync` 后台线程不消费。Phase 7 agent loop 接入时会真正读这个 flag；现阶段点 Stop 只是把按钮状态改了
