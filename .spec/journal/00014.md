## 做了什么

把 `gnb loc` 的扫描结果接进 dashboard，新增 **LOC** tab，提供分类柱图 + 多级表格视图。同步关闭 `#00010`（其 spec 文件早被删，仅 backlog 行残留）。

1. **refactor loc 包**：原 `loc.Run` 同时做扫描 + stdout 渲染，拆出 `scan(opts)` 内部函数和导出的 `loc.Scan(opts) (*Snapshot, error)`，返回排好序的 `Snapshot{Categories[].Subs[].Leaves[]}` 树。`Run` 改为 `scan + render`，CLI 输出不变。
2. **dashboard 接入**：`handlers.go` 加 `LocVM` + `buildLocVM(includeThirdParty)`，`handleTab` 加 `case "loc"` 走 `/tab/loc?thirdparty=1` toggle。
3. **template 函数**：`server.go` 加 `intCommas`、`locBarPct`、`locShare` 三个 helper，给柱图算宽度 + 千分位渲染。
4. **tab_loc 模板**：partials.html 末尾新增 `{{define "tab_loc"}}`，左列两个 stat 卡 + 类别水平柱图（Application/Engine/Tests/ThirdParty 各自配色），右列嵌套表格（cat → sub → leaf 缩进）。htmx checkbox 切换 ThirdParty 重拉整个 tab。
5. **入口**：`layout.html` tab strip 加 LOC 按钮（柱图 svg 图标）+ render 分支。
6. **#00010 同步关闭**：该任务的旧 spec 早已删除；`TODO.md` 待规划段的残留行也一并清掉。
