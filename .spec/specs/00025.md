# #00025 AIService Agent 化 — Phase 9：集成测试 + 文档收尾

## 背景

完成前置 phase 后做一次端到端验证 + 沉淀文档，让其他贡献者能加自定义工具。

## 范围

### In Scope

- **集成测试脚本** `tests/integration/ai_agent_e2e.py`（或 `gnb ai-test` 子命令）：
  - 启动本地 llama-server
  - 启动 `gkNextVisualTest` headless 模式（如不支持，新增 `--ai-eval` 模式）
  - 跑 prompts.json 里 10 条任务：
    - "列出场景中所有节点"
    - "把所有名字含 'crate' 的物体往 X 方向移动 2 米"
    - "读 `src/Engine/Runtime/Engine.hpp` 列出 NextEngine 的公开方法"
    - "把当前选中物体的 RenderComponent.castShadow 改成 false"
    - "找出场景里没有 PhysicsComponent 的物体"
    - 等
  - 断言成功率 ≥ 70%（小模型基线）+ 步数中位数 < 8
- **新增文档** `AGENT_GUIDE/AIAgentSystem.md`：
  - 架构图（provider → agent loop → tool registry）
  - 如何写自定义工具（继承 `IAITool`、注册到 registry）
  - 主线程 marshal 注意事项
  - 安全沙箱配置
  - 故障排查（PID 文件、tool 解析失败、grounding 触发）
- **更新** `AGENTS.md`：
  - 在 "Key Architectural Patterns" 加 "AI Agent System" 一节
  - 在 "Local LLM" 节追加引擎集成说明
- **更新** `AGENT_GUIDE/ReflectionSystem.md`：补充 "反射如何被 agent tool 自动暴露"
- `gnb loc` 验证：总 LOC 增量 < 5k，第一方代码仍在 < 50k 目标内

### Out of Scope

- 工具市场 / 插件机制（远期）
