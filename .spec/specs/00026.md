# #00026 让SCAD的LLM生成结果更加结构化，按module拆分文件

## 背景

目前的生成方式，都是生成一个整的SCAD文本，然后交给引擎加载出来，左侧的结构树只能用于预览，对于多模块的模型，不太好分而治之。

## 目标

我希望LLM直接能按module生成多文件结构的层级化SCAD模型，一个module对应一个文件。在左侧场景树的module支持独立显示，右侧也可以针对这个独立的module独立修改。（参考assets/scad/ancient_city.scad的结构）
