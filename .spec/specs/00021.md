# #00021 AIService Agent 化 — Phase 5：编辑器工具集

## 背景

把 [FEditorScriptExecutor](../../src/Application/Editor/gkNextEditor/AI/EditorScriptExecutor.hpp) 的命令面包成 `IAITool`，让 agent loop 能直接调用，替代当前"LLM 输出 markdown → 引擎正则抽 EditorScript → 串行执行"的路径。

## 范围

### In Scope

- 新增 `src/Application/Editor/gkNextEditor/AI/EditorTools.{hpp,cpp}`，工具列表：
  - **查询**（`RequiresMainThread=true`，只读快照）：
    - `scene_list_nodes(pattern?, max=200)`、`scene_get_node(nameOrId)`、`scene_get_selection()`
    - `scene_list_scenes()`、`scene_get_component_schema(componentType)` — **从 entt::meta 动态拿**，删除 `BuildPropertyTypeInfo` 那段硬塞 prompt
    - `scene_summary()` — 节点总数 + 类型直方图（短）
    - `assets_list(category?, max=200)`
  - **修改**（`RequiresMainThread=true`）：
    - `scene_select / rename / delete / duplicate / move / rotate / scale`
    - `scene_set_property(nodeRef, componentType, property, value)`
    - `scene_rename_pattern(regex, replace)`
  - **动作**（部分 high-risk）：
    - `scene_load_scene(name)` — `IsHighRisk=true`，工具 Execute 时不直接执行，而是把 `FDeferredEditorAction` 推入 `pendingActions_` 并返回 `"DEFERRED:<id>"` 让 LLM 知道在等用户确认
    - `scene_add_scene(name)`、`camera_focus_selected`、`cvar(name, value?)`
  - **逃生口**（多行复杂操作）：
    - `run_editor_script(text)` — 调 `FEditorScriptExecutor::ExecuteScriptText`
    - `run_javascript(code)` — 调 `EvalJavaScript`
- 构造 helper `RegisterEditorTools(FToolRegistry&, NextEngine&, EditorContext*, FEditorScriptExecutor&)`
- 所有写工具都走 `MainThreadDispatcher`（agent 在后台线程，写入回主线程）
- 单元测试 `Tests/AI/EditorToolsTests.cpp`：headless EditorContext mock，覆盖 select / move / set_property / list_nodes + high-risk DEFERRED 路径

### Out of Scope

- `FEditorAIService` 切换到 agent 模式（→ #00023）
- AI Panel UI 升级（→ #00022）

## 改动文件

- 新：`src/Application/Editor/gkNextEditor/AI/EditorTools.{hpp,cpp}`

- 新：`src/Tests/AI/EditorToolsTests.cpp`

## 验收

- `gkNextUnitTests "[AI][EditorTools]"` 全绿
- 通过 agent loop mock 调用 `scene_move` 能成功修改 mock scene 的节点变换

## 风险

- 反射拿组件 schema：entt::meta 当前在 `Engine/Runtime/Subsystems/Reflection` 注册，**确认 schema 在 Subsystem 启动后才可用**；工具构造时延迟绑定，每次 Execute 时重新查表
- DEFERRED 工具的"返回字符串告诉 LLM 等待"语义模型可能不理解：在工具 `Schema().description` 里明确写"this tool defers execution to user confirmation"
