# #00020 AIService Agent 化 — Phase 4：通用知识工具（移植 gnb）

## 背景

让 LLM 自主探索代码 / 资产 / git 状态，替代当前在 `BuildSystemPrompt` 里硬塞场景 + 反射的做法。完整 C++ 移植 [gnb chat_tools.go](../../tools/gnb/internal/dashboard/chat_tools.go) 的工具集（不通过外部进程，引擎自包含）。

## 范围

### In Scope

- 新增 `src/Engine/Runtime/Subsystems/AI/Tools/RepoTools.{hpp,cpp}`，每个工具一个 `IAITool` 子类：
  - `list_dir(path, max_entries=200)`
  - `find_files(pattern, max_results=100)`
  - `search_text(query, path?, max_results=50, case_insensitive=false)` — std::regex 或简化版 ripgrep-like
  - `find_symbol(symbol, lang_filter?)` — `[A-Za-z_][A-Za-z0-9_]*` 边界匹配
  - `read_file(path, start_line?, end_line?)` — 默认带行号前缀，max 512KB
  - `git_log(max_count=20, path?)`
  - `git_show(rev, path?)`
  - `run_cmd(cmd)` — 白名单：`git status/diff/log/show/ls-files/rev-parse/branch`，禁 shell 元字符
- 安全沙箱（参考 gnb 实现）：
  - `safeRepoPath(repoRoot, userPath) → optional<absPath>`：拒绝路径逃逸、符号链接出仓库
  - `isProbablyBinary(bytes)`：NUL 字节或非 UTF-8 触发 `binary file (skipped)`
  - 默认 deny glob：`.env*`、`*.key`、`*.pem`、`assets/configs/ai_config.json` 自身
- 构造 helper `RegisterRepoTools(FToolRegistry&, std::filesystem::path repoRoot, bool readOnly=true)`
- 所有工具 `RequiresMainThread()=false`
- 单元测试 `Tests/AI/RepoToolsTests.cpp`：每工具 happy path + 至少 1 边界（路径逃逸 / 二进制 / 空查询 / 不存在文件）

### Out of Scope

- 编辑器场景工具（→ #00021）

- Windows 路径分隔符 / 大小写：sandbox 用 `std::filesystem::weakly_canonical` + `lexically_normal`
