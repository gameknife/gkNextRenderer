# #00023 AIService Agent 化 — Phase 7：FEditorAIService 切到 agent 模式

## 背景

前置 phase 已备齐 agent loop + 工具。本期把 [FEditorAIService](../../src/Application/Editor/gkNextEditor/AI/EditorAIService.cpp) 主路径切换过去，**砍掉大 system prompt**，让 LLM 自取知识。

## 范围

### In Scope

- 重写 `FEditorAIService::GenerateAsync`：
  - 构造本地 `FToolRegistry`：
    - `RegisterRepoTools(reg, repoRoot, /*readOnly*/true)` — 允许读源码 / git，不允许 run_cmd 修改
    - `RegisterEditorTools(reg, engine, &ctx, executor_)`
  - 构造 seed messages：
    - `system`: 30 行精简版（角色定位 + 工具使用规则 + 输出语言 = 用户语言 + high-risk 二次确认提示）
    - `user`: 用户原 prompt + 附 `BuildSelectionContext` 简短文本（当前选中名 / id 列表）
  - 调 `FAgentLoop::Run(...)`，回写 `lastResponse_` 为 transcript（带最终 assistant 回答 + 折叠的步骤摘要）
- **删掉** `BuildSceneContext` / `BuildSceneAssetCatalog` / `BuildPropertyTypeInfo` / `BuildAvailableCommands` 在主路径的调用（保留函数本体不删，给 legacy 模式用）
- 配置 `ai_config.json: useAgentLoop=true` 走新路径；false 走老的 `ExtractFromResponse` 路径
- `pendingActions_` 走 Phase 5 的 DEFERRED 工具结果
- 旧的 `ExtractFromResponse` 代码块抽取保留作为 agent 模式下的最后一道 fallback（当模型仍输出 markdown 而非 tool calls 时）
