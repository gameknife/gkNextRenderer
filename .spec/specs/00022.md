# #00022 AIService Agent 化 — Phase 6：AI Panel UI 升级

## 背景

agent loop 多步执行需要把过程可视化（参考 gnb dashboard chat 的步骤气泡），让用户能看到 LLM 在调什么工具、读什么文件，并支持中途取消。

## 范围

### In Scope

- 改 [AIPanel](../../src/Application/Editor/gkNextEditor/Panels/AIPanel.cpp)：
  - 新增"Agent 步骤"折叠区，listen `FAgentEventSink` 事件流
  - 每步渲染：`step N · tool_name · summary`（点开看 `argsJson` / `resultJson`）
  - 状态指示：`生成中 / 调用 list_dir / 调用 scene_move / 等待用户确认`
  - **停止**按钮 → 设置 `cancelFlag`，agent 循环下一步前退出
  - **步数上限** spin box，默认 12，范围 1–30
  - **模式开关**：Agent / Legacy single-shot（写到 `ai_config.json`）
- `FAgentEventSink` 实现一个 thread-safe 环形 buffer（lock + 容量 256），UI 每帧 pop
- 已有 `pendingActions_` 确认条 UI 保留，high-risk 工具触发时弹

### Out of Scope

- 替换 `FEditorAIService` 内部逻辑（→ #00023）

## 改动文件

- 改：`src/Application/Editor/gkNextEditor/Panels/AIPanel.{hpp,cpp}`
- 改：`src/Application/Editor/gkNextEditor/AI/EditorAIService.{hpp,cpp}`（暴露 event sink getter）
- 改：`assets/configs/ai_config.json`（新增 `useAgentLoop`、`maxAgentSteps`）

## 验收

- 启动编辑器 → 输入"列出场景节点" → 面板能看到 `step 1 · scene_list_nodes · 17 nodes`
- 按"停止"能立即终止 loop（≤1 步内）
- 模式开关切回 legacy 仍正常工作

## 风险

- ImGui 事件流性能：event 数量上限 + 自动折叠超过 10 步前的细节
- 中文显示：复用现有 `AIPanel` 字体加载逻辑
