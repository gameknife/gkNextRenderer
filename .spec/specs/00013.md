# #00013 重构 SwModernNoAmbient 渲染流程：Lambert+IBL + CSM 阴影

## 背景与目标

`ERT_LegacyDeferredNoAmbient` 当前是 `LegacyDeferred::SoftwareModernRenderer` 的"换 shader + simpleCompose"特殊形态，shader 的天光用 `SampleIBLRough * 0.03` 这种魔法系数，太阳光 N·L 直接乘，**没有阴影**。本期把它整理成一条干净独立的轻量级管线，作为后续可扩展到移动端 / 浏览器的"传统渲染"基线。

核心目标：

- **renderer 类独立**：拆出 `Vulkan::NoAmbientDeferred::Renderer`，不再复用 `SoftwareModernRenderer` 的 `simpleComposeOnly` 开关
- **shading 标准化**：天光使用 HDRSH irradiance（去 magic number），太阳光走标准 Lambert + 阴影
- **直接光阴影**：参考 `VisibilityPipeline` 流程，做一次 GPU **CSM**（4 cascade）shadowmap 生成 pass，放在 `VulkanBaseRenderer::PreRender` 中所有 renderer 共用
- **bindless 暴露**：CSM array 通过 `BindlessTexture.slang` 第三组 binding 暴露，shader 端统一以 Bindless 取样

## 范围

### In Scope

- 新 renderer 类 `NoAmbientDeferred::Renderer`，注册到 `VulkanBaseRenderer::RegisterLogicRenderer(ERT_LegacyDeferredNoAmbient)`

## 关键技术决策

### 1. CSM 矩阵切分策略

参考 UE Stable CSM：log-uniform 混合 split。给定主相机近远平面 `[n, f]`，4 段距离：

```
for i in 0..3:
    uniform = n + (f - n) * (i+1)/4
    log = n * (f/n)^((i+1)/4)
    splits[i] = lerp(uniform, log, 0.75)   // 0.75 偏 log
```

每段在 view space 算 8 个 corner，转 world space，再用 `lookAt(center - sunDir * radius, center, up)` + `ortho(-r, r, -r, r, -2r, 2r)` 围裹。

CascadeSplits 存 view-space z（负值）便于 shader 直接比对。

### 2. Shadow Pass pipeline

镜像 [VisibilityPipeline](../../src/Engine/Rendering/PipelineCommon/CommonComputePipeline.cpp:157)：

- `VkPipelineVertexInputState` 空（vertex 从 `Bindless.GetGpuscene().Vertices` 拉，复刻 `Rast.VisibilityPass.vert.slang` 的索引方式）
- RenderPass：1 个 depth attachment，无 color，`VK_ATTACHMENT_LOAD_OP_CLEAR`，`finalLayout = VK_IMAGE_LAYOUT_DEPTH_STENCIL_READ_ONLY_OPTIMAL`
- 4 个 FrameBuffer，各自绑定 array 的一个 layer view
- Pipeline state：`depthBiasEnable=VK_TRUE`，`depthBiasConstantFactor=1.25f`，`depthBiasSlopeFactor=1.75f`（标准起点，调整空间）
- Push constant：`Assets::GPUScene` + `uint cascadeIndex`（塞 `custom_data_0` 即可，少一个 push range）
- 不用 GPU cull 输出（视椎不同），先全场景 indirect draw；后续可加 per-cascade cull

帧调用：

```cpp
// PreRender, in visibility pass 之后
if (GetScene().GetEnvSettings().HasSun) {
    SCOPED_GPU_TIMER("shadow pass");
    shadowMapPass_->Draw(commandBuffer, imageIndex);  // 内部 4 个 render pass，写入 4 个 layer
    // barrier: depth-write -> shader-read
}
```

### 3. Bindless 扩展

[BindlessTexture.slang](../../assets/shaders/common/BindlessTexture.slang) 新增：

```slang
[[vk::binding(2, 0)]] __DynamicResource ShadowMapArray[];

namespace Bindless {
    public static const int SM_SUN_CSM = 0;   // slot id

    public Sampler2DArray GetShadowMap(int index) {
        return ShadowMapArray[NonUniformResourceIndex(index)].as<Sampler2DArray>();
    }
}
```

`GlobalTexturePool::DescriptorSetManager` 加第三个 binding type `VK_DESCRIPTOR_TYPE_COMBINED_IMAGE_SAMPLER`（或 sampled image + sampler 分开，跟现有 RT_ 一致即可）。

PCF 采样统一封装 `Common.SampleShadowCSM(worldPos, normal, viewZ)`，返回 `[0,1]` 阴影系数。

### 4. shading shader 改写

```slang
// 重写 Core.SwModernNoAmbient.comp.slang 光照段
float3 N = normalize(hitVertex.Normal);
float3 V = -primaryRayDir;
float3 albedo = primaryAlbedo.rgb;

float3 ambient = float3(0);
if (Camera.HasSky) {
    float3 irr = Common.SampleIBLRough(Camera.SkyIdx, N, Camera.SkyRotation).rgb * Camera.SkyIntensity;
    ambient = albedo * irr;   // SH-based irradiance, 已含 π 归一化由 EvaluateSH 处理
}

float3 direct = float3(0);
if (Camera.HasSun) {
    float NoL = max(dot(Camera.SunDirection.xyz, N), 0);
    float viewZ = -mul(Camera.ModelView, float4(hitVertex.Position, 1)).z;  // positive depth
    float shadow = Common.SampleShadowCSM(hitVertex.Position, N, viewZ);
    direct = albedo * Camera.SunColor.rgb * (NoL * shadow * M_1_PI);
}

float3 emissive = (material.MaterialModel == MaterialDiffuseLight)
    ? min(material.Diffuse.rgb, float3(1000)) : float3(0);

color = float4(ambient + direct + emissive, 1);
```

去掉旧的 `0.3183098861837907f` 这类硬编码 1/π（统一用 `M_1_PI`），去掉 `0.03` magic number。

### 5. 旧 CPU shadow 路径处理

- `Scene::cpuShadowMap_`：资源声明保留，本期不删（避免编译链锁住）
- `FCPUAccelerationStructure::GenShadowMap`：函数体保留，**调用点删掉**（grep 一次确认所有引用），加 TODO 注释引向 #00013 后续清理
- `EnvSettings::GetSunViewProjection()`：保留实现，但加注释标记 deprecated，调用方迁移到新的 `GetSunCascadeViewProjection(camera, idx)` 接口
- 老 `Camera.SunViewProjection` UBO 字段：本期可以直接换成 `SunCascadeViewProjection[4]`，PathTracer 的 `FShadowMapDirectIlluminator::getShadow` 临时改成读 `[0]` 保持工作，结果可能错但能编译

## 风险与回退

| 风险 | 说明 | 缓解 |
| -- | ---- | ---- |
| Bindless layout 改动影响所有 pipeline | 第三组 binding 加入后所有共享 GlobalTexturePool 的 pipeline layout 都要重建 | 单独提交，逐 pipeline 验证；保留 default empty descriptor 防 layout 不一致 |
| CSM split / bias 调参 | 第一次落地参数大概率不对，会出现 acne / peter panning | shader 里所有阈值参数化到 `CascadeSplits` 或 UBO，方便 ImGui 调 |
| Shadow array 写入 layout | depth array 的 layer view 创建、layout transition 容易出错 | 参考现有 `cpuShadowMap_` 创建路径；多写注释 |
| PathTracer 字段断链 | 旧 `SunViewProjection` 被多处引用 | 字段保留为兼容 alias = `SunCascadeViewProjection[0]`，PathTracer 临时读 [0] |
| Vulkan validation 报错 | 新 RenderPass / FrameBuffer 配置错 | 全程开 validation layer，编译期就修 |
